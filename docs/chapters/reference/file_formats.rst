===================
Output file formats
===================

The toolbox writes plain-text outputs that are easy to inspect manually and
easy to parse from downstream scripts.

Core files
----------

``README.txt``
   Human-readable run summary describing the method, atlas, settings, and main
   outputs.

``metadata.json``
   Machine-readable summary of run settings such as atlas, hemisphere, region
   scope, null method, permutation count, enrichment configuration, and
   workflow-specific bookkeeping.

``regional_values.tsv``
   Regional values aligned to the selected atlas subset for ``corr`` and
   ``pls``.

Correlation outputs
-------------------

``corr_genes.tsv``
   Ranked gene table with:

   ``gene``
      Gene symbol.

   ``score``
      Observed correlation between the imaging vector and the gene-expression
      pattern across the selected regions.

   ``p``
      Sign-aware empirical p-value from the gene-specific permutation null.

   ``fdr``
      Benjamini-Hochberg correction across the full correlation gene table.

   ``maxT``
      Family-wise correction from the largest absolute null correlation seen in
      each permutation.

``gsea_corr_results.tsv``
   Correlation GSEA results with:

   - ``Term``
   - ``es``
   - ``nes``
   - ``p_val``
   - ``fdr``

   Here ``nes`` and ``fdr`` are calibrated to the external nulls generated by
   the toolbox rather than to GSEApy's internal permutation engine.

``ora_corr_up.tsv`` and ``ora_corr_down.tsv``
   ORA results for positive and negative gene subsets. These tables include:

   - ``Term``
   - ``overlap_size``
   - ``set_size``
   - ``selected_size``
   - ``universe_size``
   - ``enrichment_ratio``
   - ``odds_ratio``
   - ``odds_ratio_ci_low``
   - ``odds_ratio_ci_high``
   - ``p_value``
   - ``fdr``
   - ``overlap_genes``

PLS outputs
-----------

``pls_summary.tsv``
   Per-component summary with:

   ``component``
      1-based component index.

   ``variance_explained``
      Response-side variance explained by that component alone.

   ``cumulative_variance``
      Cumulative explained variance through that component.

   ``p``
      Component-level empirical p-value comparing the observed cumulative
      explained variance with permuted fits.

``pls_component_<n>.tsv``
   Ranked per-component gene table with:

   ``gene``
      Gene symbol.

   ``weight``
      Observed aligned gene weight for that component.

   ``zscore``
      Observed weight divided by the permutation standard deviation.

   ``p``
      Sign-aware empirical p-value from the permutation weight null for that
      component.

   ``fdr``
      Benjamini-Hochberg correction across genes within that component.

   ``maxT``
      Family-wise correction from the largest absolute null weight seen in each
      permutation for that component.

``gsea_pls<n>_results.tsv``
   GSEA results for one PLS component with the same column meanings as the
   correlation GSEA table.

``ora_pls<n>_up.tsv`` and ``ora_pls<n>_down.tsv``
   ORA results for one PLS component, using the same schema as the correlation
   ORA tables.

Gene PCA outputs
----------------

``gene_pca_scores.tsv``
   Regional PCA scores with one ``PC<n>`` column per retained component.

``gene_pca_loadings.tsv``
   Per-gene loadings with one ``PC<n>`` column per retained component.

``gene_pca_variance.tsv``
   Per-component explained variance and cumulative variance.

``matched_genes.txt``
   Requested genes that were found in the atlas expression matrix after
   filtering.

``brain_filtered_genes.txt``
   Requested genes removed by the packaged brain-gene filter before atlas
   matching.

``missing_genes.txt``
   Requested genes that remained unmatched after filtering.

GEDAR outputs
-------------

``gedar_scores.tsv``
   Regional GEDAR weighted-expression scores. In standard mode the main columns
   are:

   - ``id``
   - ``label``
   - ``hemisphere``
   - ``structure``
   - ``score``
   - ``score_z``

   In split mode the score columns become:

   - ``score_up``
   - ``score_up_z``
   - ``score_down``
   - ``score_down_z``

``gedar_genes.tsv``
   Matched gene table used for the GEDAR calculation. Depending on the chosen
   mode, this can include:

   - original gene symbol
   - input weight column
   - input rank column
   - selected-gene flags
   - effective weight used in the regional GEDAR average

``gedar_excluded.tsv``
   Input rows removed before atlas matching, including invalid values,
   duplicate gene symbols, and genes outside the packaged brain-gene filter.

``matched_genes.txt`` and ``missing_genes.txt``
   The genes from the weighted input table that were found or not found in the
   atlas expression matrix after cleaning.
