Hybrid preset: schaefer-400-aseg

This packaged atlas uses the cortical parcels from 'schaefer-400' and appends the same aseg-derived subcortical add-on used in 'dk'.
The cortical expression matrix is copied from the packaged base atlas.
The subcortical expression rows are copied from the packaged dk atlas after aligning them to the base atlas gene ordering.
Packaged genes: 15675
Transferred aseg parcels: 15
Volumetric merged atlas available: yes

Notes
-----
The Schaefer 400 atlas has more, smaller cortical regions, so it ends up with
slightly fewer genes after `abagen` filtering and donor averaging.
Rows in the expression archive follow `atlas-schaefer-400_labels.csv`, and gene
columns follow `../shared/genes-ahba-15675.npy`.
