Desikan-Killiany atlas expression assets
========================================

Build summary
-------------
- Atlas id: `dk`
- Atlas label: `Desikan-Killiany (83 regions)`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Volumetric atlas: `atlas-DK_1mm.nii.gz`
- Reference 2 mm atlas: `atlas-DK_2mm.nii.gz`
- Surface annotations: `atlas-DK_fsa5_lh_aparc.annot`, `atlas-DK_fsa5_rh_aparc.annot`
- Atlas metadata table: `atlas-DK_labels.csv`

abagen parameters
-----------------
- `atlas_image=atlas-DK_1mm.nii.gz`
- `atlas_info=atlas-DK_labels.csv`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`

Outputs in this folder
----------------------
- `atlas-DK_gene_expression_data.npz`: 83 regions x 15,677 genes
  compressed NumPy archive with `ids`, `regions`, `genes`, and `float32` `values`
- `atlas-dk_sample_counts.csv`
- `atlas-DK_labels.csv`
- `provenance.json`

Region summary
--------------
- Hemisphere counts: 41 left, 41 right, 1 bilateral
- Structure counts: 68 cortex, 15 subcortex/brainstem
- Right hemisphere expression rows were generated by `abagen` with `lr_mirror="leftright"`

Notes
-----
This atlas was rebuilt from the packaged DK atlas assets already tracked in the repository. The generated expression matrix is the one consumed by the v2 API for `hemisphere="left"` and `hemisphere="both"` workflows.
