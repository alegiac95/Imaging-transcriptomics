Desikan-Killiany atlas files
============================

Build summary
-------------
- Atlas id: `dk`
- Atlas label: `Desikan-Killiany (83 regions)`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Volumetric atlas: `atlas-DK_1mm.nii.gz`
- Reference 2 mm atlas: `atlas-DK_2mm.nii.gz`
- Surface annotations: `atlas-DK_fsa5_lh_aparc.annot`, `atlas-DK_fsa5_rh_aparc.annot`
- Atlas metadata table: `atlas-DK_labels.csv`

abagen parameters
-----------------
- `atlas_image=atlas-DK_1mm.nii.gz`
- `atlas_info=atlas-DK_labels.csv`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`
