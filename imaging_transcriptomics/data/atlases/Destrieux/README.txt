Destrieux atlas files
=====================

Build summary
-------------
- Atlas id: `destrieux`
- Atlas label: `Destrieux`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Volumetric atlas: `atlas-Destrieux_1mm.nii.gz`
- Reference 2 mm atlas: `atlas-Destrieux_2mm.nii.gz`
- Asset preparation sources:
  - 1 mm lateralized atlas from `nilearn.datasets.fetch_atlas_destrieux_2009(lateralized=True)`
  - 2 mm atlas produced by nearest-neighbor resampling to the DK 2 mm grid
- Atlas metadata table: `atlas-destrieux_labels.csv`

abagen parameters
-----------------
- `atlas_image=atlas-Destrieux_1mm.nii.gz`
- `atlas_info=atlas-destrieux_labels.csv`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`

Files in this folder
--------------------
- `atlas-destrieux_gene_expression_data.npz`: 148 regions x 15,675 genes
  compressed NumPy archive with `float32` values only
- `atlas-destrieux_sample_counts.csv`
- `atlas-destrieux_labels.csv`
- `../shared/genes-ahba-15675.npy`
- `provenance.json`

Region summary
--------------
- Hemisphere counts: 74 left, 74 right
- Structure counts: 148 cortex
- Right-side rows were generated by `abagen` with `lr_mirror="leftright"`

Notes
-----
The label table was cleaned up during atlas preparation so side labels and
region names stay consistent.
Rows in the expression archive follow `atlas-destrieux_labels.csv`, and gene
columns follow `../shared/genes-ahba-15675.npy`.
