Schaefer 100 atlas expression assets
====================================

Build summary
-------------
- Atlas id: `schaefer-100`
- Atlas label: `Schaefer 100 (100 regions)`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Volumetric atlas: `atlas-Schaefer_100_1mm.nii.gz`
- Reference 2 mm atlas: `atlas-Schaefer_100_2mm.nii.gz`
- Surface annotations: `atlas-Schaefer_100_lh_aparc.annot`, `atlas-Schaefer_100_rh_aparc.annot`
- Atlas metadata table: `atlas-Schaefer_100_labels.csv`

abagen parameters
-----------------
- `atlas_image=atlas-Schaefer_100_1mm.nii.gz`
- `atlas_info=atlas-Schaefer_100_labels.csv`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`

Outputs in this folder
----------------------
- `atlas-Schaefer_100_gene_expression_data.npz`: 100 regions x 15,677 genes
  compressed NumPy archive with `ids`, `regions`, `genes`, and `float32` `values`
- `atlas-schaefer-100_sample_counts.csv`
- `atlas-Schaefer_100_labels.csv`
- `provenance.json`

Region summary
--------------
- Hemisphere counts: 50 left, 50 right
- Structure counts: 100 cortex
- Right hemisphere expression rows were generated by `abagen` with `lr_mirror="leftright"`

Notes
-----
This atlas was rebuilt from the packaged Schaefer 100 atlas assets already tracked in the repository. The resulting matrix is cortical only and is used directly by the v2 atlas registry.
