Schaefer 400 atlas expression assets
====================================

Build summary
-------------
- Atlas id: `schaefer-400`
- Atlas label: `Schaefer 400`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Volumetric atlas: `atlas-Schaefer_400_1mm.nii.gz`
- Reference 2 mm atlas: `atlas-Schaefer_400_2mm.nii.gz`
- Surface annotations: `atlas-Schaefer_400_lh_aparc.annot`, `atlas-Schaefer_400_rh_aparc.annot`
- Asset preparation sources:
  - volume maps from `nilearn.datasets.fetch_atlas_schaefer_2018`
  - fsaverage annotations from `netneurotools.datasets.fetch_schaefer2018`
- Atlas metadata table: `atlas-schaefer-400_labels.csv`

abagen parameters
-----------------
- `atlas_image=atlas-Schaefer_400_1mm.nii.gz`
- `atlas_info=atlas-schaefer-400_labels.csv`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`

Outputs in this folder
----------------------
- `atlas-schaefer-400_gene_expression_data.npz`: 400 regions x 15,675 genes
  compressed NumPy archive with `ids`, `regions`, `genes`, and `float32` `values`
- `atlas-schaefer-400_sample_counts.csv`
- `atlas-schaefer-400_labels.csv`
- `provenance.json`

Region summary
--------------
- Hemisphere counts: 200 left, 200 right
- Structure counts: 400 cortex
- Right hemisphere expression rows were generated by `abagen` with `lr_mirror="leftright"`

Notes
-----
The Schaefer 400 atlas uses a higher-resolution cortical parcellation, so its retained gene set is slightly smaller than the lower-resolution presets after abagen filtering and donor aggregation.
