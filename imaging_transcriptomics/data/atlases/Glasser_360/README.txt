Glasser 360 atlas files
=======================

Build summary
-------------
- Atlas id: `glasser-360`
- Atlas label: `Glasser 360`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Surface label GIFTIs: `atlas-Glasser_360_lh.label.gii`, `atlas-Glasser_360_rh.label.gii`
- Surface geometry: `atlas-Glasser_360_lh.surf.gii`, `atlas-Glasser_360_rh.surf.gii`
- Asset preparation sources:
  - parcel labels from `netneurotools.datasets.fetch_mmpall`
  - fsLR 32k midthickness geometry from `neuromaps.datasets.fetch_atlas("fslr", "32k")`
- Atlas metadata table: `atlas-glasser-360_labels.csv`

abagen parameters
-----------------
- `atlas_image=(lh.label.gii, rh.label.gii)`
- `atlas_info=atlas-glasser-360_labels.csv`
- `geometry=(lh.surf.gii, rh.surf.gii)`
- `space="fslr"`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`

Files in this folder
--------------------
- `atlas-glasser-360_gene_expression_data.npz`: 360 regions x 15,675 genes
  compressed NumPy archive with `float32` values only
- `atlas-glasser-360_sample_counts.csv`
- `atlas-glasser-360_labels.csv`
- `../shared/genes-ahba-15675.npy`
- `provenance.json`

Region summary
--------------
- Hemisphere counts: 180 left, 180 right
- Structure counts: 360 cortex
- Right-side rows were generated by `abagen` with `lr_mirror="leftright"`

Notes
-----
This is the only included atlas in the repo that starts from surface files.
Rows in the expression archive follow `atlas-glasser-360_labels.csv`, and gene
columns follow `../shared/genes-ahba-15675.npy`.
