Hybrid preset: schaefer-200-aseg

This packaged atlas uses the cortical parcels from 'schaefer-200' and appends the same aseg-derived subcortical add-on used in 'dk'.
The cortical expression matrix is copied from the packaged base atlas.
The subcortical expression rows are copied from the packaged dk atlas after aligning them to the base atlas gene ordering.
Packaged genes: 15677
Transferred aseg parcels: 15
Volumetric merged atlas available: yes
