Schaefer 200 atlas expression assets
====================================

Build summary
-------------
- Atlas id: `schaefer-200`
- Atlas label: `Schaefer 200`
- Build entrypoint: `tools/build_preset_atlases.py`
- Expression builder: `imaging_transcriptomics.build_expression_assets()`
- abagen version: `0.1.3`
- Build environment: `.conda/imt-atlas-build`

Source assets used
------------------
- Volumetric atlas: `atlas-Schaefer_200_1mm.nii.gz`
- Reference 2 mm atlas: `atlas-Schaefer_200_2mm.nii.gz`
- Surface annotations: `atlas-Schaefer_200_lh_aparc.annot`, `atlas-Schaefer_200_rh_aparc.annot`
- Asset preparation sources:
  - volume maps from `nilearn.datasets.fetch_atlas_schaefer_2018`
  - fsaverage annotations from `netneurotools.datasets.fetch_schaefer2018`
- Atlas metadata table: `atlas-schaefer-200_labels.csv`

abagen parameters
-----------------
- `atlas_image=atlas-Schaefer_200_1mm.nii.gz`
- `atlas_info=atlas-schaefer-200_labels.csv`
- `donors="all"`
- `lr_mirror="leftright"`
- `missing=None`
- `n_proc=4`
- `return_counts=True`
- `return_report=True`

Outputs in this folder
----------------------
- `atlas-schaefer-200_gene_expression_data.npz`: 200 regions x 15,677 genes
  compressed NumPy archive with `float32` values only
- `atlas-schaefer-200_sample_counts.csv`
- `atlas-schaefer-200_labels.csv`
- `../shared/genes-ahba-15677.npy`
- `provenance.json`

Region summary
--------------
- Hemisphere counts: 100 left, 100 right
- Structure counts: 200 cortex
- Right hemisphere expression rows were generated by `abagen` with `lr_mirror="leftright"`

Notes
-----
The Schaefer 200 atlas assets were prepared locally before running abagen so that the repository can ship a ready-to-run preset instead of requiring end users to rebuild it.
Rows in the expression archive are aligned to `atlas-schaefer-200_labels.csv`,
and gene columns are aligned to `../shared/genes-ahba-15677.npy`.
